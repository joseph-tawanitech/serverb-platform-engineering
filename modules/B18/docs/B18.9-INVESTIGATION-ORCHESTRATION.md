# B18.9 Investigation Orchestration

## Purpose

B18.9 provides the orchestration layer for the B18 Incident Investigation
and Root Cause Analysis framework.

The orchestration layer connects the existing B18 investigation components
into a single deterministic investigation workflow.

B18.9 does not replace or duplicate the domain logic implemented by the
individual B18 engines.
