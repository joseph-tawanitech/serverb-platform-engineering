## 2. Objective

B18.4 introduces the Incident Timeline Layer for TAP incident investigation.

The purpose of the timeline is to transform normalized infrastructure evidence into a chronological representation of events.

The timeline answers:

- What happened?
- When did it happen?
- Which evidence supports the event?
- Which infrastructure resource was involved?
- Which source produced the evidence?

The timeline establishes chronological sequence.

It does not independently claim causality or root cause.

Causal analysis is performed by later B18 components such as correlation, hypothesis generation, evidence sufficiency analysis and RCA.
