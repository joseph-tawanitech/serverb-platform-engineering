# 1. Objective

B18.8 introduces the Root Cause Analysis (RCA) layer for the TAP incident investigation pipeline.

The purpose of this layer is to transform the results of hypothesis generation and evidence sufficiency evaluation into a structured, deterministic RCA conclusion.

B18.8 does not allow an RCA conclusion to be produced solely from an unstructured AI response.

The RCA result is derived from structured investigation inputs:

- Incident ID
- Hypothesis
- Evidence Sufficiency result
- Evidence records

The resulting RCA is validated before it is returned.

---

# 2. Design Principle

The RCA layer separates:

1. Evidence
2. Hypothesis
3. Evidence sufficiency
4. Root cause conclusion

The investigation pipeline therefore follows:

Evidence → Hypothesis → Evidence Sufficiency → RCA

This separation prevents the system from treating an observed symptom or an unverified hypothesis as an established root cause.

---

# 3. RCA Status Model

B18.8 defines four RCA states.

## 3.1 NOT_ESTABLISHED

The root cause has not been established.

This occurs when the available evidence is insufficient to establish the hypothesis as the root cause.

The RCA contains no root-cause statement.

Confidence is set to `0.0`.
