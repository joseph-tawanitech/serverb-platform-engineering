# B20.6 — Security Investigation

## Status

**PASS — Deterministic Investigation Context Layer**

B20.6 establishes the TAP B20 security investigation context layer.

The component prepares structured investigation context from authorized security evidence. It does not perform AI reasoning and does not authorize or execute security actions.

## 1. Purpose

B20.6 provides the investigation context layer between security evidence and the B20.5 AI Security Operator.

B20.6 prepares structured investigation context. It does not perform AI reasoning, authorize remediation, or execute infrastructure changes.

## 2. Responsibilities

- identify investigation, environment, asset, and question
- validate authorized SecurityEvidence objects
- validate UTC timestamps
- record missing evidence
- provide deterministic evidence summaries
- remain provider-neutral
- accept and validate the existing B19 `AIContextRequest`
- consume RAG context without owning RAG retrieval

## 3. Architecture

B20.4 Monitoring → B20.3 Security Evidence → B19 RAG → B20.6 Investigation → B20.5 AI Security Operator → TAP Policy/Authorization → Governed Action → Verification → Audit

## 4. Security Boundary

B20.6 does not grant execution authority. AI recommendations remain subject to TAP policy, authorization, execution controls, verification, and recording.

## 5. B19 RAG Integration

B20.6 now integrates with the existing B19 RAG architecture through the typed `AIContextRequest` contract.

B19 remains responsible for knowledge retrieval and RAG context construction. B20.6 does not perform retrieval itself and does not create a second RAG system.

The integration validates that an `AIContextRequest` belongs to the same investigation and preserves the existing provider-neutral boundary between RAG context and AI investigation.

This is contract-level integration. Live end-to-end B19 retrieval into a B20.6 investigation remains a future implementation increment.

B20.5 local Qwen3:4b full investigation execution remains deferred because of the documented local AI runtime capacity limitation.
