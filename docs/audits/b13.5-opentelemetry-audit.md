## 14. Security

The Collector is deployed internally as a Kubernetes ClusterIP service.

No external LoadBalancer or NodePort was configured for the Collector.

Telemetry ingestion is therefore internal to the Kubernetes environment unless an explicit external exposure is later authorized.

Execution authority is not granted to OpenTelemetry.

OpenTelemetry is an observability component and does not provide remediation or execution authority.
